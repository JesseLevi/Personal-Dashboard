# Note editor (`/notities/[noteId]`)
Figma: `Desktop/Notes/Edit` `3934:33463` · `Mobile/Notes/Edit` `3934:33422` (back `3978:14820` / `3934:33426`, delete `3978:14809` / `3978:14839`, Content `4067:20020` / `3978:14850`, placeholder `4067:20021` / `4067:20017`). Only the empty page, header and EditingBar are drawn; prose, tables, menus, images, links and TOC are Claude-designed on request (#329-#342, ADR-0021/0022/0023) · Code: `app/(app)/notities/[noteId]/{page,NoteEditor,useNoteSave}`, `lib/notes/extensions.ts`, `.tiptap` block in `app/globals.css`

## Anatomy
One client component for the whole page body (like `RecipeDetailPage`). Header: icon-only back `Button` | `NoteSaveStatus` (hidden during delete confirm) | `NoteMarkdownMenu` (holds "Verwijderen"). Then `EditingBar` (`design/notes/EditingBar.md`) and the content wrapper: `EditorContent`, `TableMenu`, `NoteTableHandles`, word count, backlinks and the editor-only floaters (`SlashMenu`, `NoteLinkMenu`, `NoteBubbleMenu`, `NoteBlockHandle`, `LinkPopover`).

- No title field (title = first line, `deriveTitle` runs server-side), no save button, no category picker (category is fixed at creation from the `/notities` column "+"). Figma's hidden "Categorie" text on the back button, the extra mobile `Button/Default` `3934:33424` (the shell hamburger) and the drawn `Sidebar Collapsed=Yes` are residue.
- `lib/notes/extensions.ts` is the one fixed content whitelist (Architecture 133), reusable by a future renderer; never a second list. Editor-only UI (Placeholder, Typography, MarkdownPaste, NoteImageUpload, CharacterCount, SlashCommand, NoteLinkSuggestion) is added at the `useEditor()` call site. Tiptap packages are pinned to `@tiptap/core`'s 3.30.0; `immediatelyRender: false` for the App Router.
- Editor root `text-base font-medium` (Figma placeholder is `font-semibold`; typed text moved to medium in #386); placeholder colour is `text-text-placeholder` through a `::before` rule (`content: attr()` has no utility).

## Deliberate decisions
- Delete reuses the in-place two-step confirm (`DeleteConfirm inline`, as `RecipeDetailPage`/`CategoryPanel`); the question line names what is irreversibly deleted. Pending autosave is `discard()`ed first. Delete is the last, separated row of `NoteMarkdownMenu`. (#233, #386)
- Autosave: 1000 ms (coalesces a typing burst). `SaveController` owns debounce, in-flight and status; "saved" only from a resolved `{ success: true }`, a rejection is a failure, a newer edit during a write stays "saving". Error is a destructive Button that re-sends the failed snapshot. Flush on unmount and on `visibilitychange` hidden (neither covers the other); `beforeunload` warns while not "saved". No optimistic success state: it once masked a broken write path. (#233, #334)
- `settled` ref + `CreationQuiet`: `UniqueID`/`TableOfContents` assign heading ids in deferred `create` handlers; updates are ignored until `settled`, so opening an old note never saves it or bumps `updated_at`, and load transactions skip `TrailingNode` so the caret does not move. (#342)
- Prose: Tailwind's type scale through `@apply` (H1 `text-3xl font-extrabold`, H2 `2xl bold`, H3 `xl bold`, body `leading-relaxed`, `max-width: 70ch`). Weights 600/700/800 so levels differ on both axes. Headings add space above; the sibling rule is `.tiptap > * + *` (top level only). List and blockquote padding use `inline-*` tokens (`stack-*` is pixel-identical but the wrong axis). Inline code has no background; links only underline. (#263, #329)
- Task items: native checkbox in the Checkbox atom's tokens at `size-5`, check glyph is a CSS mask (follows dark mode), checked text `text-secondary` + line-through. Selector `li[data-checked]` because the node view omits `data-type`. `a11y.checkboxLabel` returns the item text (default is English, whitelist has no next-intl). `toPlainText` adds no checkbox prefix (it would leak into `deriveTitle` and search). (#329)
- Tables: no margin on `table`; TipTap always wraps it in `div.tableWrapper`, which takes the sibling margin, and a margin inside an `overflow-x: auto` box is trapped. The wrapper draws the rounded outer border, cells inner lines only. `table-layout: fixed` + `resizable` + `cellMinWidth` 96, because `auto` re-split columns on every keystroke; only a dragged column gets `colwidth`, legacy tables share equally, wide tables scroll inside the wrapper. `th` gets `surface-secondary` (else `withHeaderRow` is invisible) and `text-align: left`. `.selectedCell` is `surface-highlight-blue` (stone step in dark) so a selection never reads as a header. (#235, #330)
- `TableMenu`: BubbleMenu, `isActive('table')` and fine pointer, anchored to the wrapper's top-left; a "Table" trigger opens a labelled `role="menu"` row per `TABLE_COMMANDS` (the icon set has no row/column glyphs). Inapplicable rows are `aria-disabled` `opacity-40` and stay focusable; the destructive row is `text-priority-urgent` on a transparent row. Alt+F10 focuses the trigger. No bubble on touch: the EditingBar table mode is the mobile surface. Reorder handles: `design/notes/NoteTableHandles.md`. (#330, #387)
- Bubble menu: non-empty `TextSelection` only, fine pointer, never in code or with the table menu showing; "Turn into" reuses `BLOCK_TYPE_MENU`. `role="toolbar"`, Alt+F10 focuses, Escape returns to the editor. (#331)
- Link popover: one per editor; bubble, EditingBar and Mod-K ask through `requestLinkPopover` (a DOM event). Anchors to the link button on desktop, the whole bar on mobile (the button may be scrolled away), the selection for Mod-K; re-measures on `visualViewport`. `lib/notes/link-url.ts` is the only validator (also the extension's `isAllowedUri`): http, https, mailto; bare `example.com` becomes `https://`; `javascript:`, `data:`, `ftp:`, `//host` rejected, so bad stored hrefs load as plain text. `openOnClick: false`. (#331)
- Slash menu: `@tiptap/suggestion` + a small external store (`useSyncExternalStore`, no tippy). Opens only at block start or after a space, never in code, no "Table" in a table. Items come from `lib/notes/slash-items.ts` (single source, also feeds the EditingBar overflow and the block menu). Portalled `role="listbox"`; the editor keeps DOM focus (mousedown prevented so the iOS keyboard stays) and carries `aria-activedescendant`. (#332)
- Code blocks keep node name `codeBlock` + attr `language` so stored blocks load. Grammars load by dynamic `import()`, then `rehighlightCodeBlocks` dispatches a content-neutral, history-less transaction (the lowlight plugin only recomputes on doc change). No auto-detection; colours reuse existing text tokens. `Details` collapsed content is only `hidden`, so search includes it. (#336)
- Markdown is paste/copy/export only; storage stays JSON. `lib/notes/markdown.ts` is the sole importer of `@tiptap/markdown` (about 60 kB, `await import`; a test fails on a static import). Paste converts only plain text with a block marker and no `text/html`, not in code; parsed JSON goes through `sanitizeToSchema`; raw HTML is never interpreted. A node without `renderMarkdown` needs one `MARKDOWN_ENTRIES` entry plus a fixture. (#337)
- Block handle: `DragHandle` registers its own plugin, so it is mounted in `NoteEditor.tsx`, not the whitelist. Absolutely positioned left of the hovered top-level block so the column never moves; fine pointer only; one transaction so undo restores; held visible while its menu is open (`lockDragHandle` meta). `lib/notes/block-commands.ts` is node-type agnostic and never removes the last block. `Mod-Shift-ArrowUp/Down` is the only keyboard route. (#335)
- Images: `src` must start with `/api/note-image/` (parseHTML, no input rule, external markdown images become paragraphs): no route may introduce an external picture (ADR-0022). Upload shows a widget decoration, never a node, so a failure leaves nothing to autosave; error is `role="alert"` for 8 s. Enter on a selected image focuses its alt field. `toPlainText` writes alt as its own line. (#339)
- Note links: inline atom `noteLink` on `Mention` (`noteId` + `label`, what `extractNoteLinkIds` saves). `[[` is the editor-only `NoteLinkSuggestion`, so a read-only renderer carries no menu. The chip shows the target's current title; an unresolved id is a muted non-clickable "Verwijderde notitie". It is a real `<a href>` (modified click keeps new-tab). (#341)
- TOC rail: `absolute` in the free space right of the 70ch column, `w-44`, `xl:` only, from 3 headings, so the column never shifts; no mobile menu. Active = last heading in the top quarter of the viewport; `scrollParent: undefined` disables the extension's own listener. (#342)

## Token gaps and flags
- `spacing-flag`: header `gap-4` (Figma 16 unbound, `SPACE_BETWEEN`); delete-confirm `gap-4` / `gap-2` (copied from `RecipeDetailPage`); `pb-[calc(4rem+env(safe-area-inset-bottom))] md:py-2` on the content wrapper (4rem is a code-only reservation clearing the 48px mobile bar; `md:py-2` is the desktop Content's unbound 8px, kept raw rather than guessing between `stack-sm` and `component-sm`).
- No font-size or weight tokens. Raw CSS not gated by `check:raw-spacing`: 2px blockquote rule and focus/selection outlines, the 1.25rem checkbox, `70ch`.
- Generic icon reuse where glyphs are missing (table menu, link Open = `Link` / Remove = `Trash`, slash and block menus, broken image = `Image`); each new glyph moves the `icon--all-icons` baseline.
