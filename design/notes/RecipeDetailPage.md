# RecipeDetailPage (`/recepten/[recipeId]`)
Figma: `Pages/Recept_V2/Breakpoints` section `3997:14736`, `Recept/Mobile` `3997:14737`, `Recept/Desktop` `3997:15171`, PasAan overlays `3997:25600` / `3999:10604` · Code: `app/(app)/recepten/[recipeId]/page.tsx` (Server Component: fetch, `notFound()`, presign hero), `RecipeDetailPage.tsx` (`"use client"` page-level composition, not in `figma-map.json`), plus page-local `NutritionalDataRow.tsx`, `PasAanPanel.tsx`, `SourceLink.tsx` (own notes: `NutritionalDataRow.md`, `PasAanPanel.md`)

## Anatomy
Top to bottom: header row (back arrow left, buttons right, all breakpoints: `AnimatedAddToBasketButton`, Delen, Ellipsis menu holding Bewerken and Verwijderen), then a text line for share/delete errors, 2:1 hero, title block (h1, `NutritionalDataRow`, optional coverage line, `SourceLink`), ingredient `Card`s per `group_label` (rows are `CardContentIngredient`), step `Card`s (`CardContentStep` with `Tag`s), then `RecipePanel` (edit) and `PasAanPanel`. The root only adds `pr-page-right-equal`; `main` supplies the other padding (#205).

## Deliberate decisions
- No `PageHeader`: Figma's header has no `<h1>` slot (back arrow left, buttons right; the title sits below the hero), so it is a plain `flex justify-between` row (#127).
- "Voeg toe aan mand" sends the whole recipe via `sendRecipeToShoppingList({ recipeId, targetPortions: portions })`, using the session `portions`, never `recipe.servings`. The real `ActionResult` is returned so `AnimatedAddToBasketButton` plays "Toegevoegd" only on success; failure display is undesigned (#178, #179, #290).
- Ingredient rows use `swipeAction="cart"`: swipe reveals an icon-only add button that calls `addIngredientToShoppingList` for that one ingredient, scaled to session `portions`. The aria label is per item ("Voeg {name} toe aan mand"); `cardContentIngredient.addToCartLabel` stays generic for stories. The action merges into an existing same name+unit row instead of inserting (#179).
- No category `Tag` row: no fetched node draws one, a recorded scope boundary (#127). Time is rendered (V2 draws it) (#160).
- The Ellipsis menu is the only home of Bewerken/Verwijderen at every breakpoint (Figma's desktop buttons were retired by user decision, #466). It is undesigned (`3778:5434` has no panel): icon-only `Button` plus `Dropdown` rows as in `TeDoenHeader`, placed with `usePopoverPosition` (`anchor="right"`, `prefer="below"`; `docs/incidents.md`, 2026-08-18) (#127).
- Delete confirm is the `CardDetailPanel` two-step precedent (#94) in the header row (`DeleteConfirm layout="inline"`); the menu item drives `deleteConfirming`. On success `router.push("/recepten")`, since the route can no longer resolve; errors render inline (#127).
- Delen (filled `Button`, `Share`; icon-only below `md` with a permanent `aria-label`, text from `md` up) opens `MemberSearchPanel` with `confirmLabel` "Delen" and `confirmIcon` `Check`. Picking someone calls `shareRecipe` (`recepten/actions.ts`, which calls `inviteMember({ resource: "recipe" })`): success shows a `Toast` "Gedeeld met {voornaam}" (first name only: `displayName`, else `sharedUnnamedLabel`), failures show `sharing.errors.*` (`already-shared`, `rate-limited`, ...) in `priority-urgent`. Sharing sends an offer for a copy, never live access (ADR-0036).
- `RecipePanel` edit mode shows its own Verwijderen, a second delete affordance next to the header's. Its `onDeleteRecipe` wraps `deleteRecipe` with the same redirect rather than `router.refresh()` (#127).
- Ungrouped ingredients (`group_label` null) share one Card titled `ingredientsDefaultTitle` ("Ingrediënten"). This reversed #160's untitled card on an explicit user instruction. Groups render in first-seen order; a label recurring non-contiguously merges into its first bucket (#166).
- Row dividers sit between rows only (`divider={index < length - 1}`); see `CardContentIngredient.md` (#160).
- Step Tags show quantity+unit+name in one neutral `Tag` ("2 tbs Chia Seeds"), as Figma draws them. Short unit labels (`recipes.unitsShort`) are used only there; ingredient cards keep long `recipes.units` labels. Quantity-less ingredients show the name only. Tags come from the display list via `ingredientsById` (so they match the cards); unknown ids are dropped, and a step with none renders `withIngredientTags={false}` (#153, #164).
- Portions and unit system are display-only session state: never written to `recipe.servings`, no column, reset on navigation. `page.tsx` keys the page on `recipe.id`. `portions` floors at 1 in `PortionStepper` (#153). Scaling is `lib/recipes/scaling.ts` mapped over `recipe.ingredients`, once per render, feeding both cards and Tags; `editTarget` keeps the real stored quantities. `scaleIngredientRow(s)` catches `InvalidPortionCountError` and falls back to the unscaled quantity so a render never crashes (#128).
- Fully `"use client"` rather than the narrow island #128 asked for: edit/delete/router already need page-level client state, and no Supabase access is added (#128).
- Hero is `aspect-[2/1]` at every breakpoint, by user order. `page.tsx` presigns the `full` variant and passes `thumbnailUrl`; the `<img>` is the LCP element (`loading="eager"`, `fetchPriority="high"`, explicit 1280x640, `alt=""` because the title is adjacent text) with a one-shot `onError` swap to the route URL (`useImageFallback`). Missing R2 config or a foreign stem gives `null`: a same-aspect `bg-surface-primary` placeholder renders, so the layout does not jump. Delivery details in `CardContentRecipe.md` (#153, #171, #391).
- `notFound()` covers missing, not-owned and signed-out alike (the query returns `null` for all three) (#127).
- No Ladle story: a full route body like `ReceptenBoard`; `SourceLink` has its own (#127).
- Nutrition row (V2): per-person values come from `summarizeRecipeNutrition(recipe.ingredients, recipe.servings)` on the original unscaled quantities, deliberately not `portions` / `unitSystem`. Per-person nutrition is portion-invariant (scaling and dividing cancel), and feeding a display-only unit conversion into nutrition math would launder it. The servings pill shows `portions` and is disabled (no annotation, no handler invented). Pills and fibre: `NutritionalDataRow.md` (#160, #166).
- Macros count only recognised rows: a row the calculator cannot weigh or that has no NEVO values is left out, never counted as 0. When rows are missing a `text-secondary` line reads "Op basis van {counted} van {total} ingrediënten", and each such row gets the "niet meegeteld" marker (precedence over "controleren"), which opens the edit panel. Rows without a quantity ("naar smaak") are neither counted nor flagged. Claude-designed on request.
- Pas aan trigger is `Card`'s `settings` slot (icon-only `Settings2`), rendered on the first ingredient group's Card only, since Personen/Eenheid are recipe-wide. Figma samples a single instance; extending to multiple groups is our reasoned reading (#160).
- `PasAanPanel` reuses `PortionStepper` for Personen: Figma draws one `Button` with `Plus` in both icon slots (the same slip as `portion-stepper-figma-draws-plus-twice`). The user dropped Figma's footer "Verwijderen" (2026-08-05); only "Opslaan" remains and it applies the draft, then closes. The panel keeps draft state reset on every open and calls `onApply` only from Opslaan, so X, overlay, Escape and drag-to-close discard it (#160).
- Unit conversion `convertToUnitSystem` (`lib/recipes/units.ts`) is membership-based, not normalising: only units foreign to the target system convert, onto one flagship unit per magnitude (metric: gram / milliliter; US: ounce / cup). Count units (stuk, snufje, scoop, naar_smaak) pass through. Output is rounded to 2 decimals. Default `metric`: Dutch-metric recipes render as entered. Flagship units are our choice, not Figma. Normalising unconditionally once turned "2 eetlepel" into "30 milliliter"; `tests/recipes-units.test.ts` locks same-system units unchanged (#160).
- Kitchen units (`lib/recipes/kitchen-units.ts`, composed with scaling in one pass): `convertToKitchenUnit` intercepts two flagship landings only. Mass landing on `ounce` under US becomes cup (stepping down to tbsp/tsp below 1/4 cup and 1 tbsp) when a cup mass resolves; a foreign volume landing on `milliliter` under metric becomes gram when its mass resolves. `milliliter`/`deciliter`/`liter`/`eetlepel`/`theelepel` are never touched ("375 ml stays 375 ml"). Masses ride on each row as plain data (`kitchenUnitMasses`; functions cannot cross the server-to-client boundary), from the already-batched nutrition mass fetch (#164, #157).
- `formatQuantityFraction` renders an ASCII slash ladder (eighths, quarters, thirds, halves; 5% relative tolerance plus `1e-9` for IEEE noise, nearest candidate wins, ADR-0014 §6); mass quantities stay decimal. `formatQuantity` remains for non-ingredient figures (#164).
- Import (#318): `SourceLink` ("Bron: host", Claude-designed) shows the host as plain text, `target="_blank" rel="noopener noreferrer"`, only for a valid stored https URL. `needs_review` rows get the "controleren" marker (`CardContentIngredient.md`).
- Target basket (#429, ADR-0035): `page.tsx` loads `getRecipeBaskets()` (own plus accepted shared, RLS decides; `shared` = not the owner, or at least one accepted share) and passes `baskets` down. One basket: nothing changes, the actions get no `listId` and use the default. More than one: the header button and each ingredient cart button first open a basket popover; the chosen id goes to `sendRecipeToShoppingList` / `addIngredientToShoppingList` as `listId`, and an RLS refusal is the existing failed state. Not designed in Figma: existing `Dropdown` + `Button`, icons `User` / `Users`.

## Token gaps and flags
Converted from measured `boundVariables` (#219, #205): root gap `gap-page-stack` (`spacing/layout/page-stack`, Main `3997:14738` / `3997:15173`); step list wrapper `gap-page-stack`; Knoppen inner group `gap-inline-xl` (`3997:14742` / `3997:15176`); Title frame `py-component-lg` (`3997:15946` / `3997:15181`).

Left raw behind `spacing-flag:` comments:
- Header row `gap-4`: Header (`3997:14740` / `3997:15174`) has `itemSpacing: 16` but an empty `boundVariables` (SPACE_BETWEEN); the value is a code-only fallback.
- Buttons wrapper `gap-4`: desktop Knoppen (`3997:15176`) spaces its buttons at 20 (`inline/gap-xl`); code keeps 16 between basket button, Delen and the menu. Converting would change 16px to 20px. Needs a design call: draw the new header in Figma.
- Hero / placeholder `rounded-xl`: "image 63" (`3997:14745` / `3997:15180`) has `cornerRadius: 12` but empty `boundVariables`, unbound despite matching `radius/card`.
- Title frame `gap-6`: `itemSpacing: 24` is unbound there (only the padding binds), despite matching `stack/xl` and `page-stack`.
- Ingredient-cards wrapper `gap-6 md:flex-row`: Figma keeps cards as flat vertical siblings (`page-stack`, 24) with only one ingredient Card, so nothing binds a row-axis gap. Do not apply `gap-stack-xl` / `gap-page-stack` to it.
