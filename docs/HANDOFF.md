   - **Nutrition columns exist but stay empty in Phase 4.** `NULL` means unknown and must never be coerced to `0`. NEVO data must never enter the repo (licence); USDA FoodData Central is the backbone, CIQUAL an allowed supplement with source+version attribution; never mix sources within one ingredient row.
   - **The `unit` enum is `public.recipe_unit`** (#130's migration). Reuse it; never declare a second. `tests/recipes-units-enum-sync.test.ts` fails on drift against `UNIT_CODES`.

   - **`PortionStepper` does not clamp** — decrementing at 1 emits 0, deliberately: portion state is caller-owned and **#128 owns the minimum**.
